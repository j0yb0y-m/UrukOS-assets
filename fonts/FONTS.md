# Fonts

No font binaries in this repo. Install these Fedora packages:

| Package | Use |
|---|---|
| google-noto-sans-fonts | UI default |
| google-noto-naskh-arabic-fonts | Arabic text (RTL) |
| google-noto-kufi-arabic-fonts | Arabic headings |
| jetbrains-mono-fonts | terminal / monospace |
| fontawesome-fonts-web | icons |

Verify each with `dnf5 repoquery <name>` before adding to a package list.
